## 本轮升级

### 机房演进时钟（V13.8 / V13.9 新增）

把 V5.4 里唯一值钱、却在 V13 系列失传的机制移植回来并重做。

- 13 时段 × 15 分钟：T+0 → T+195min，08:00 → 11:00
- 四格实时 KPI：负载 / 进风温度 / 回送温差 / 单柜功率，越限自动转红
- 事件流按「谁发现了什么」记录：边缘小 AI 发现趋势 → 证据不足不报警 → 首次越限只记异常点 → 连续两段超限才联合提醒 → 调空调需安全主管授权 → 告警保留 → 恢复观察 → 解除但留史
- 入口在页签栏右侧 `⏱ 演进时钟`，打开时自动折叠右下语音 dock，关闭自动还原
- 对外接口 `window.YT_CLOCK`

意义：V13.8 原来只能演「现在怎么样」，现在能演**「不处理，十五分钟后会怎样」**。

### V15 真实浏览器验收

README 此前的口径是「浏览器被策略阻止，不能宣称通过验收」。本轮 Chromium 实测 15 项全部通过：

页面加载 · 案例加载 · AI 团队执行 · 审计事件写入 · 六维指标 · 雷达图 · Wilson 置信区间（84.3%，72–91.8%）· 授权门槛 · 七阶漏斗 · 下一步推进 · 三路对照 · JSON 账本导出 · 协作网络渲染 · 零运行时报错

内核测试 `node tests/test-engine.js` 同时通过。

## 在本地运行（局域网）

Windows 双击 `启动服务.bat`，窗口会打印本机局域网地址；其他设备访问 `http://<本机IP>:8080`。

Linux / macOS：

```bash
./start.sh
```

站点零外部依赖 —— 无 CDN、无远程字体、无 localhost 调用，断网可运行。

## 边界

- 所有数据为合成数据，不代表真实生产指标
- V15 账本为浏览器内存只追加数组 + 非密码学链式校验，**不具备生产级不可篡改审计或多用户持久化**
- 小宇为渲染图 + CSS 动画，非实时 WebGL 骨骼数字人；语音依赖浏览器 TTS
- 真实内网集成、专业数据校准、生产级权限治理均未实现

详细升级记录见 [UPGRADE.md](UPGRADE.md)。
